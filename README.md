# 央视新闻 · 每日摘要（新闻联播 + 央视财经）

自动抓取央视《新闻联播》文字版 + 央视财经《经济信息联播》（CCTV-2），本地规则归纳分类，发布成手机/电脑都能看的网页。
**不需要自己电脑开机**：GitHub Actions 云端每天定时抓取，GitHub Pages 免费托管。

## 工作原理

```
GitHub Actions (每天 21:30 北京时间)          你（手机/任何电脑浏览器）
┌────────────────────────────────┐          ┌──────────────────────┐
│ cctv_news.py 抓取央视网文字版    │          │ 每日速览：两来源切换   │
│ 关键词分类 + 首句摘要(无AI)      │  ──发布──▶ │ 分类浏览 / 搜索       │
│ 结果存 docs/data/*.json         │          │ 往期归类：按分类回看   │
└────────────────────────────────┘          │ 昨日/今日对比：数据变化 │
                                             └──────────────────────┘
```

- **前端**：`docs/` 纯原生 HTML/CSS/JS，无框架无构建，响应式 + 深色模式
  - **每日速览**：同一日期可在「新闻联播 / 央视财经 / 全部」间切换来源，分类筛选 + 搜索
  - **往期归类**：聚合全部历史日期，按分类（时政要闻、金融市场、国际新闻…）+ 来源筛选，按日期倒序回看
  - **昨日/今日对比**：任选一天与前一天对比——总量与各来源条数、分类分布条形图、今日新增 / 昨日独有话题（支持 `#compare` 深链直达）
- **后端**：`cctv_news.py` 纯 Python 标准库（urllib + 正则），归纳为本地规则，不调用大模型
- **数据**：`docs/data/YYYY-MM-DD.json` 每天一份（`sources` 下分 xwlb / jjxxll 两源，含分类、要点、一句话摘要和正文）；`docs/data/archive.json` 为往期归类聚合

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 看每天摘要 | 直接访问网站（GitHub Pages 地址见仓库 About 或 Settings → Pages） |
| 查看往期归类 | 网站顶部切到「往期归类」，选分类 + 来源即可回看历史 |
| 昨日/今日对比 | 网站顶部切到「昨日/今日对比」，点选日期即可看与前一天的数据差异 |
| 抓某个往期区间 | 仓库页 Actions → Fetch & Deploy → Run workflow → 填起止日期 |
| 本地跑一下试试 | `python cctv_news.py`（输出 md/html 到 data/） |
| 只生成网站数据 | `python cctv_news.py --site --days 30` |

## 说明

- 当天内容约 20:30 后在央视网上线，云端 21:30 抓取，所以晚上十点后看当天的最稳
- 每次运行会自动补齐近 30 天缺失的日期；断更/缺财经源都会自动补上
- 《经济信息联播》经 CNTV 官方接口获取（每天约 30+ 条，含官方一句话简介）；《新闻联播》抓文字版全文
- 新闻内容版权归央视网，本项目仅为个人学习用途的摘要归档

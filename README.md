# 新闻联播 · 每日摘要

自动抓取央视网《新闻联播》文字版，本地规则归纳分类，发布成手机/电脑都能看的网页。
**不需要自己电脑开机**：GitHub Actions 云端每天定时抓取，GitHub Pages 免费托管。

## 工作原理

```
GitHub Actions (每天 21:30 北京时间)          你（手机/任何电脑浏览器）
┌────────────────────────────────┐          ┌──────────────┐
│ cctv_news.py 抓取央视网文字版    │          │ 打开网站地址   │
│ 关键词分类 + 首句摘要(无AI)      │  ──发布──▶ │ 看要点/分类/  │
│ 结果存 docs/data/*.json        │          │ 搜索/往期回看  │
└────────────────────────────────┘          └──────────────┘
```

- **前端**：`docs/` 纯原生 HTML/CSS/JS，无框架无构建，响应式 + 深色模式
- **后端**：`cctv_news.py` 纯 Python 标准库（urllib + 正则），归纳为本地规则，不调用大模型
- **数据**：`docs/data/YYYY-MM-DD.json` 每天一份，含分类、要点、一句话摘要和全文

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 看每天摘要 | 直接访问网站（GitHub Pages 地址见仓库 About 或 Settings → Pages） |
| 抓某个往期区间 | 仓库页 Actions → Fetch & Deploy → Run workflow → 填起止日期 |
| 本地跑一下试试 | `python cctv_news.py`（输出 md/html 到 data/） |
| 只生成网站数据 | `python cctv_news.py --site --days 30` |

## 说明

- 当天内容约 20:30 后在央视网上线，云端 21:30 抓取，所以晚上十点后看当天的最稳
- 每次运行会自动补齐近 30 天缺失的日期，断更了也会自己补上
- 新闻内容版权归央视网，本项目仅为个人学习用途的摘要归档
